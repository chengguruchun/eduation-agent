# Education Agent

Education Agent is an exploration of a personalized education system built around one principle:

> **Education should adapt to the learner, while learning must eventually connect to real-world capability.**

This repository is intentionally **design-only** at the current stage. No production implementation is planned yet.

## Core Questions

1. How can an education agent continuously understand a learner without prematurely labeling them?
2. How can learning paths adapt to differences in age, prior knowledge, learning speed, interests and ways of understanding?
3. How can we avoid turning personalization into endless exploration without meaningful outcomes?
4. How can learning move from knowledge and reasoning to action, real feedback and real-world capability?

## Current Model

```text
Learner
   ↓
Observe / Diagnose
   ↓
Current Learner State
   ↓
Personalized Learning Path
   ↓
Learn / Practice
   ↓
Act
   ↓
Outcome / Feedback
   ↓
Reflection
   ↓
Update Learner State
   ↺
```

The long-term direction is not simply an AI tutor. It is a **learning-and-growth system** that connects cognition, action and feedback.

## Scope

Current phase:

- design
- architecture
- evaluation principles
- roadmap

Not yet:

- production code
- automated student scoring
- autonomous decisions about a child's future
- replacing teachers, parents or real-world institutions

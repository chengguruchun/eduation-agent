# Roadmap

## Phase 0 — Design Only

Current phase.

- define learner-state model
- define evidence model
- define adaptive learning loop
- define real-world feedback model
- define human-in-the-loop boundaries
- document evaluation principles

No production implementation yet.

## Phase 1 — Learning Diagnosis Prototype

Future exploration:

- learner state representation
- prerequisite detection
- hypothesis-based diagnosis
- confidence and evidence tracking
- adaptive next-step selection

## Phase 2 — Personalized Learning Loop

Explore:

```text
diagnose → choose experience → learn → practice → evaluate → update
```

Compare different learning strategies rather than assuming one teaching method works for everyone.

## Phase 3 — Action-Based Learning

Introduce structured projects:

- build
- experiment
- create
- collaborate
- solve an open-ended problem

Evaluation expands from answers to execution and outcomes.

## Phase 4 — Physical / Real-world Learning

Explore controlled environments such as:

- robotics
- AI farming
- science experiments
- maker environments
- community projects

The objective is to connect learning with real feedback rather than replacing reality with games.

## Phase 5 — Longitudinal Growth System

Explore long-term evidence:

```text
Learner State
    ↓
Learning Experiences
    ↓
Actions
    ↓
Outcomes
    ↓
Feedback
    ↓
Growth Trajectory
```

The system should remain revisable and avoid treating early observations as permanent judgments.

## Non-goals

At this stage, the project will not:

- build a production education platform
- replace teachers or parents
- assign permanent ability labels
- optimize children solely for standardized scores
- make autonomous high-impact decisions about a child's future

The project first focuses on the architecture and philosophy of an adaptive learning-and-growth agent.
